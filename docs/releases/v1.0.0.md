Claude Usage puts your Claude limit on a screen of its own: a desk panel for a 5-inch, 800×480 touch display that shows how much of your current 5-hour block is gone and whether you'll hit the limit before it resets. No API keys and no setup. It reads what Claude Code already keeps on your machine, and it keeps working with the network off.

## What's in it

- **Usage.** The current block from start to reset, stacked by model, with your burn rate projected to the reset and the time you'll hit the limit if you're on pace to. The percentage and reset times come from the same endpoint Claude Code's `/usage` asks, so the numbers match.
- **System.** CPU and GPU load, clocks, temperatures, memory, VRAM and fan, with a live graph for each.
- **Macros.** A Stream Deck style grid of glass keys for media, shortcuts, apps and PowerShell, set up in one JSON file that reloads as you save it.

Swipe between the three pages. Every page is built to be read from a few feet away, and the theme button in the header switches between dark, light, and following Windows.

## Install

1. Download the `.msi` or the `-setup.exe` below and run it.
2. Windows may say **"Windows protected your PC"**, because the installer isn't code-signed yet. Choose **More info**, then **Run anyway**.
3. Make sure Claude Code is installed and signed in on the same PC. The panel reads its logs and its login; it never asks for a key.

The window opens at 800×480. If it lands on the wrong display, the button with four corners in the header moves it onto the panel.

### Optional

- **CPU temperature** needs [LibreHardwareMonitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor) running with its remote web server on port 8085. The README has the one-time setup.
- **GPU readouts** need an NVIDIA card. Without one, the GPU card hides.
- **Macros** live in `%APPDATA%\dev.xander.claude-usage\macros.json`, created with a starter set on first run.

## Good to know

- Before the first live reading succeeds, the limit is estimated from your busiest past block and can be well off. The header says **Estimated** until then.
- The usage endpoint is undocumented and could change. If it does, the panel keeps working from your local logs and the last known limit, and the header says what went wrong.
- Shortcut macros can't type into an app running as administrator unless the panel runs as administrator too. This is a Windows rule.
- This build is for Windows.
